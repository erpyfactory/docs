# Erpy Factory docs

Source of the Erpy Factory documentation, built with [Starlight](https://starlight.astro.build)
and published to https://erpyfactory.github.io/docs.

```bash
npm install
npm run dev      # http://localhost:4321/docs
npm run build
```

Pages live in `src/content/docs`. A step in the quick start is added only after it has been tried
on a real repository.
