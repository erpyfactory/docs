---
title: What is Erpy Factory
description: What Erpy Factory does, and what you need to use it.
---

Erpy Factory turns the issues in your GitHub repository into pull requests.

It is built around **Erpyd**, a GitHub App that you install on your repositories. You
describe the work in an issue. Erpyd works in your repository: it plans the change, writes the
code, runs your checks, and hands the result back as a pull request for you to review. Review
feedback and failing checks can be handed back to it the same way.

## Early access

Erpy Factory is in early access and focuses on Odoo add-on repositories. These docs grow one step
at a time: a step is added here only after it has been tried on a real repository.

## What you need

- A GitHub repository, owned by an organization or a personal account.
- Permission to install a GitHub App on that account. For an organization that means being an
  owner of it.
